# Light Review Cycle

Run this cycle on explicit invocation or when a procedure requires it, such as the completion check of small work in [Main Workflow](skill://main-workflow) or in ToSpec, Main Workflow's plan-mode checkpoints or a finalization gate. Follow the [Blind Review Cycle](skill://blind-review-cycle) contract with the agent `spotty` in place of `smarty`.

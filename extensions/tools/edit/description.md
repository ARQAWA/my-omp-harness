Replace exact text in files. Give path, old_string and new_string for one replacement, or edits: [{path, old_string, new_string, replace_all?}, …] for several replacements in one call, in one or many files. Edits of different files run in parallel; edits of one file apply in the given order, and after a failed edit the rest of that file's edits are skipped. A file that another edit or write is still changing is refused as busy, and the other files are still edited. old_string must identify one place in the file: add context, or set replace_all: true to replace every occurrence. Read a file before editing it. The result lists edited, busy, failed and skipped files; a failed edit shows the nearest matching lines with line numbers.

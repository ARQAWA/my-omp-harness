Never use eval to search or read code while gathering context; grep, glob and read do that in parallel. Use eval for computation, data processing, or many tool calls whose output must be filtered in code. Use eval instead of chained grep and bash when the answer is computed over many files: counts, totals, tables, joins of several sources such as applying migrations in order or checking which config keys the code reads; one cell reads the files and returns only the result. An eval call runs alone: it waits for the calls before it and holds back the calls after it.

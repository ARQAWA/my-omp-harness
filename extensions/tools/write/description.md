Create or overwrite files. Give path and content for one file, or files: [{path, content}, …] to write several files at once; they are written in parallel. A file that another write is still writing is refused as busy and the other files are still written; the result lists written, busy and failed files. Internal URLs work as in the built-in write: agent:// sends a message, local:// writes a session file, xd:// calls a tool device, and archive and SQLite paths write entries. A response has an output limit: write a file longer than about 400 lines in parts, the first part with write and the rest appended with edit, so one call never runs into the limit and loses the response.
